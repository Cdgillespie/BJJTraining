# My Training — GitHub Pages starter

A mobile-friendly, recurring weekly workout planner. It is a static app: no server, account system, or paid hosting is required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new repository (for example, `my-training`).
2. Download and unzip this project.
3. Upload `index.html` and this `README.md` to the repository's root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.
7. Wait a minute or two. GitHub will show your site address on the Pages settings screen.

## Add it to your iPhone

1. Open your published site in Safari.
2. Tap the Share icon.
3. Choose **Add to Home Screen**.

## Important data note

Your schedule, routines, notes, and completion history are saved in the browser's local storage on that device. GitHub Pages hosts the app code; it does not sync personal workout data between devices. Use **Progress → Export backup** periodically and keep the JSON backup somewhere safe. Import it on the same or another device to restore your data.

## Included

- Repeating weekly schedule, editable by day
- Daily checklist with independent completion per date
- Daily notes for energy, soreness, and training reflections
- Workout library for sets, reps, and instructions
- Progress summary and JSON backup/restore
- Responsive layout for phones and desktop

This starter begins with an empty schedule so you can enter your current routine yourself.
